# Dyadic state assessment

Use the supplied state codebook and timestamped evidence timeline. Classify the
dyad as normal, fluctuation, dysregulation, or high_risk only when the evidence
supports the corresponding definition. Otherwise return insufficient evidence.

The decision must cite timestamped transcript or visual evidence. Assess the
interaction sequence and task progression rather than relying on one negative
word, one facial movement, or one isolated action.

Return JSON matching the StateAssessment schema.
